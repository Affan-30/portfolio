# Affan Shaikh — Portfolio

Minimal dark portfolio built with React + Vite.

```bash
npm install
npm run dev      # local dev
npm run build    # production build in dist/
```

Content lives in the section components in `src/` (`Projects.jsx`, `Experience.jsx`, `Skills.jsx`, `Education.jsx`, `Contact.jsx`).
`public/projects/jalsathi.svg` and `besan-mill.svg` are placeholders — replace with real screenshots and update the `image` path in `Projects.jsx`.
